# Keybindings

Everything bound on this machine, organized by layer. Generated by reading the
configs, not from memory—if anything here disagrees with what a key does, the
config wins and this file is outdated.

## Which layer catches the key first

This is the only part you need to understand for the rest to make sense. Four
layers compete for the keyboard, and their order is fixed:

```
   a key enters at the top and moves down until something consumes it

   1  Hammerspoon        system-wide event tap, sees EVERYTHING first
      cmd+alt+...             ── no app can take these away from it
      cmd+`
           │  anything that does not match keeps going
           ▼
   2  Alacritty          the focused app
      cmd+...                 ── nearly all its defaults use cmd
           │
           ▼
   3  herdr              multiplexer, inside the terminal
      ctrl+b <key>           ── prefix: press and release it
           │
           ▼
   4  fish  /  nvim      whatever runs inside the pane
      ctrl+<letter>          ── everything else
```

The split is deliberate: **Hammerspoon uses `cmd+alt`, Alacritty uses `cmd`,
herdr uses `ctrl+b`, and the apps inside use bare `ctrl+<letter>` bindings.**
That is why collisions are rare; the few that exist are listed in their own
section at the end.

## 1 · Hammerspoon—global, in every app

Defined in [`hammerspoon/init.lua`](./hammerspoon/init.lua). They work across
macOS, not just inside the terminal.

| Key | Action |
|---|---|
| `cmd` + `` ` `` | Show or hide Alacritty. Hide it if it is already in front |
| `cmd` `alt` + `1` | VS Code on the left, Helium on the right, 70/30 |
| `cmd` `alt` + `2` | Alacritty on the left, Helium on the right |
| `cmd` `alt` + `3` | TablePlus on the left, Helium on the right |
| `cmd` `alt` + `0` | Cycle the resolution between 1512×982 and 1800×1169 |
| `cmd` `alt` + `F` | Stateful zoom: expand to fill the screen; press again to restore |
| `cmd` `alt` `ctrl` + `R` | Reload the Hammerspoon config |

**Two `cmd+alt+F` zoom caveats.** The saved frame lives in memory, so reloading
Hammerspoon while zoomed loses it; the next press expands again instead of
restoring. The same happens if you move or resize the window after zooming,
because the comparison—which tolerates 4 pixels—no longer matches.

Tiling Alacritty with `cmd+alt+2` takes it **out** of `SimpleFullscreen`. Use
Alacritty's `cmd+ctrl+F`, listed in the next table, to restore its startup mode.

## 2 · Alacritty

Defined in [`alacritty/alacritty.toml`](./alacritty/alacritty.toml). There are
three, and two exist to **disable** dangerous defaults.

| Key | Action |
|---|---|
| `cmd` `ctrl` + `F` | Enter or leave fullscreen—the mode Alacritty starts in |
| `cmd` + `W` | **Disabled.** Its default is *Quit*, not “close tab”—one slip would take every agent with it |
| `cmd` + `T` | **Disabled.** herdr already multiplexes; another tab bar would only be confusing |

Both `option` keys act as `alt` (`option_as_alt = "Both"`). This makes fish's
`Alt-<key>` bindings arrive as `ESC`+key instead of composed characters.

## 3 · herdr—`ctrl+b` prefix

Press and **release** the prefix, then press the key. It is not a chord.

The prefix is set in [`herdr/config.toml`](./herdr/config.toml). `ctrl+b` is
herdr's default and is available now that tmux is no longer the outer layer. Two
bindings compete with it inside a pane: Neovim's `CTRL-B` for page up and fish's
`backward-char`.

### Declared in this repository

| Key | Action | Why it is declared |
|---|---|---|
| `ctrl+b` `shift+j` | Next workspace | herdr leaves it unbound |
| `ctrl+b` `shift+k` | Previous workspace | Same |
| `ctrl+b` `shift+1..9` | Go to workspace N | Same |
| `ctrl+b` `a` | Next agent | Same |
| `ctrl+b` `shift+a` | Previous agent | Same |
| `ctrl+b` `alt+1..9` | Go to agent N | Same |
| `ctrl+b` `s` | **Goto** | Swapped: herdr's default is `g` |
| `ctrl+b` `g` | **Settings** | Swapped: herdr's default is `s` |
| `ctrl+v` | Paste an image—**without the prefix** | Only active under `herdr --remote`, where the agent runs on the far side and cannot see the local clipboard |

The bindings use `shift+j` / `shift+k`, not `h` / `l`, because workspaces and
agents are both **vertical** lists.

**The `s` / `g` swap** deliberately reverses herdr's defaults. `s` is tmux's
jump key—`prefix+s` opens its session picker—and that muscle memory remains.
Settings is used less often, so it takes the key that loses its mnemonic.

| `ctrl+b` `-` | Horizontal split |

| `ctrl+b` `x` | Close the pane |

## 4 · fish

Configured in [`fish/config.fish`](./fish/config.fish). It uses
`fish_hybrid_key_bindings`: vi in normal mode and Emacs while typing. The cursor
shows the current mode—a block in normal mode and a blinking line in insert mode.

| Key | Action |
|---|---|
| `↑` | Search backward using the current text, while **remembering the original line** |
| `↓` | Move down; at the **bottom, open fzf** over the history |
| `ctrl+p` / `ctrl+n` | The same as `↑` / `↓`, without leaving the home row |
| `ctrl+r` | fish's **native history pager** |
| `ctrl+o` | Open the current command line in `$EDITOR` |
| `ctrl+t` | Find files with fzf and preview them with `bat` |
| `alt+c` | Find directories with fzf and enter the selected one |
| `**` + `tab` | Complete with fzf |

**Why `↑` is unusual and worthwhile.** fish does not leave search mode at the
bottom; it restores the line from *before* the search began. `↑` therefore saves
that line, and `↓` recognizes it as the bottom before opening fzf.

**`ctrl+r` belongs to fish, not fzf.** fzf claims it during initialization, and
the config deliberately overrides it afterward. History search through fzf is
still available through `↓`, which is why `FZF_CTRL_R_OPTS` remains configured
even though `ctrl+r` does not use it.

### Inside any fzf picker

| Key | Action |
|---|---|
| `ctrl+/` | Show or hide the preview |
| `ctrl+y` | Copy the selection to the clipboard and close |

### Abbreviations and aliases

These are not keybindings, but they are used in the same spirit. An `abbr`
expands when you press space, so you see the complete command before running it.

| You type | Expands to / action |
|---|---|
| `gc` | `git commit -m` |
| `gco` | `git checkout` |
| `ga` | `git add` |
| `gb` | `git branch` |
| `gd` | `git diff` |
| `e` | `code --new-window` |
| `ls` `ll` `la` `lt` | eza—basic, long, including hidden files, or a two-level tree |
| `dev` `work` `side` | Jump to the corresponding workspace |

## 5 · Neovim

Leader = **space**. Configured under [`nvim/lua/config/`](./nvim/lua/config).

### Essentials

| Key | Action |
|---|---|
| `jk` (insert mode) | Return to normal mode |
| `space` `nh` | Clear search highlighting |
| `space` `+` / `-` | Increment / decrement the number under the cursor |
| `space` `u` | Open the undo tree—the *branches* already saved by `undofile` that otherwise require `:undolist` + `:undo N` |
| `q` | Close the window—only in help, man, quickfix, checkhealth, and DAP floats |
| horizontal scroll | Deliberately **disabled** in normal, visual, and insert mode. Accidental sideways trackpad input used to move the buffer |

### LSP

These bindings appear only when a language server is attached to the buffer.

| Key | Action |
|---|---|
| `gd` | Go to definition |
| `gD` | Go to declaration; fall back to the definition if unsupported |
| `space` `ld` | Show line diagnostics in a floating window |
| `space` `li` | Toggle inlay hints |
| `space` `lf` | Format the buffer (also in visual mode) |

These are already **Neovim defaults** and are not redefined: `K` for
documentation, `grn` rename, `gra` code action, `grr` references, `gri`
implementation, `grt` type definition, and `gO` document symbols.

### Surrounding—nvim-surround

tpope-style defaults. Unlike `ci"`, which edits only the contents, these change
or add the delimiter. The plugin takes `S` in visual mode.

| Key | Action |
|---|---|
| `cs"'` | Replace double quotes with single quotes |
| `ds"` | Remove the quotes |
| `ysiw)` | Surround the word with parentheses |
| `S` (visual mode) | Surround the selection |

### Git—gitsigns

These operate on hunks inside the buffer. Commits, history, and branches still
belong to lazygit; this exists because lazygit cannot mark changed lines as you
type or stage a hunk without taking you out of the file.

| Key | Action |
|---|---|
| `]h` / `[h` | Next / previous hunk—in a diff, fall back to `]c` / `[c`, which is what a rebase needs |
| `space` `gs` | Stage the hunk (or the selected lines in visual mode) |
| `space` `gr` | Reset the hunk (or the selected lines in visual mode) |
| `space` `gp` | Preview the hunk |
| `space` `gb` | Show full blame for the line |
| `space` `gd` | Diff the file against the index |

These use `h`, not gitsigns' default `c`, because `]c` / `[c` already belong to
Tree-sitter's class motions.

### Debugging—DAP

The first keypress loads the stack (Mason, DAP, DAP UI, and nio) and performs the
action, so Neovim startup no longer pays that cost.

| Key | Action |
|---|---|
| `ctrl+8` | Start or continue |
| `ctrl+9` | Step over |
| `ctrl+0` | Step into |
| `ctrl+shift+0` | Step out |
| `space` `db` | Toggle breakpoint |
| `space` `dB` | Set a conditional breakpoint—prompts for the condition |
| `space` `dr` | Toggle the REPL |
| `space` `dl` | Repeat the last session |
| `space` `dt` | Terminate |
| `space` `du` | Show or hide the UI |
| `space` `de` | Evaluate the expression (also in visual mode) |

### Syntax navigation—Tree-sitter

| Key | Action |
|---|---|
| `]f` / `[f` | Next / previous function |
| `]c` / `[c` | Next / previous class. **In a diff, these jump between Vim changes** |
| `af` / `if` | Select the function, with or without its signature |
| `ac` / `ic` | Select the class, with or without its declaration |

### Completion—blink

The default preset, deliberately without `super-tab`: `tab` keeps indenting just
like it does everywhere else.

| Key | Action |
|---|---|
| `enter` | **Accept the highlighted item when the menu is open; otherwise insert a normal newline** |
| `ctrl+y` | Accept—the blink default remains available |
| `ctrl+n` / `ctrl+p` | Move down / up the list |
| `ctrl+e` | Close the menu |
| `tab` / `shift+tab` | Jump between snippet placeholders, and nothing else |

**The `enter` binding has a cost worth knowing:** blink highlights the first
item as soon as the menu opens (`preselect` defaults to `true`), so Enter **cannot
insert a newline** while the menu is visible. Press `ctrl+e` first when you want
the newline instead of the suggestion.

### Commands

`:W` `:Q` `:Wq` `:WQ` do the obvious thing when Shift stays pressed a little too
long. `:FormatToggle` disables format-on-save; add `!` to affect only the current
buffer.

## Collisions and which layer wins

None of these are accidental.

| Key | Contenders | Winner | Why |
|---|---|---|---|
| `cmd` + `` ` `` | Hammerspoon vs. macOS “cycle through windows” | **Hammerspoon** | Deliberately global; losing window cycling in every other app is an accepted cost |
| `ctrl+b` | herdr vs. Neovim page up vs. fish `backward-char` | **herdr** | Press it twice inside a pane to pass it through to the inner app |
| `ctrl+r` | fzf vs. fish history pager | **fish** | Rebound *after* fzf claims it. Enter fzf history through `↓` |
| `ctrl+n` / `ctrl+p` | fish vs. blink in Neovim | **Each in its own context** | Different contexts; they are never active at the same time |
| `tab` | Neovim buffers vs. indentation vs. snippets | **Depends on the mode** | Normal mode changes buffers; insert mode indents unless inside a snippet |
| `cmd+W` | Alacritty *Quit* | **Nobody** | Disabled. Its default closes everything, not one tab |

## When this list becomes outdated

Three sources that do not lie, ordered by how easy they are to consult:

- **Neovim**—`space` `fk` opens every keymap with its description.
- **herdr**—`ctrl+b` `?`.
- **Hammerspoon and Alacritty**—neither has its own listing; read
  [`hammerspoon/init.lua`](./hammerspoon/init.lua) and
  [`alacritty/alacritty.toml`](./alacritty/alacritty.toml), which are both short.
